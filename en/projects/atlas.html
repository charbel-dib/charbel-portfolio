The problem

Company analysis requires linking figures to their original documents. Before generating an answer, the system must know which document was collected, for which company and on what date.

02

Technical decisions

01

Start with official documents

SEC client, filing metadata ingestion and document downloads.

02

Structure provenance

Data models, filing identifiers, uniqueness constraints and schema migrations.

03

Check ingestion components

Downloader and parser tests establish a foundation before adding the assistant layer.

03

What the project delivers

The public repository contains initial ingestion, storage and testing components. The next goal is to combine quantitative data with qualitative evidence from corporate documents.

What I take from it

Make data provenance and quality the starting point of an AI product.
