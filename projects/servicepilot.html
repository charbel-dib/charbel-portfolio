01

Ce que le projet produit

Un SDK, une API et un espace de support exécutables localement, avec tests, scénarios d’évaluation, Docker Compose et workflows CI. Le mode par défaut est déterministe et sans LLM ; un adaptateur OpenAI est disponible en option.

02

Le problème

Répondre à une question de support demande souvent de consulter plusieurs outils. Donner à un agent le droit d’écrire dans ces outils introduit une autre question : qui autorise exactement quelle action ?

03

Les choix techniques

01

Trois outils de lecture

Recherche de procédures autorisées, consultation d’une API de statut et recherche d’incidents. Le modèle n’a pas d’outil direct de création de ticket.

02

Une proposition avant l’action

Le contenu proposé est figé, associé à un propriétaire, à une empreinte et à une expiration. Le serveur vérifie la validation et les droits au moment de l’écriture.

03

Un workflow que l’on peut reprendre

LangGraph et SQLite conservent l’état. La création du ticket est idempotente, pour éviter les doublons lors d’une reprise.

04

Évaluation

Le dépôt documente des tests logiciels et des scénarios hors ligne, avec Docker Compose et CI. Ils concernent le workflow et ses règles, pas la qualité d’un LLM en conditions réelles. Les mécanismes de contrôle décrits ici ne sont pas présentés comme des tests réexécutés pour ce portfolio.

Scénario de démonstration

Scénario illustratif sur données fictives : un service est indisponible. Le workflow consulte la procédure, le statut et les incidents, propose un ticket figé, puis attend l’accord de l’utilisateur. Le serveur vérifie les droits avant de créer le ticket.

Ce que j’en retiens

Traiter les autorisations et la validation comme des règles du logiciel, indépendantes des instructions données au modèle.

05

Périmètre & limites

Preuve de concept sur données fictives. Les tests hors ligne ne démontrent ni la qualité d’un modèle réel, ni une résistance générale aux injections. La version actuelle utilise notamment des jetons statiques et une base SQLite locale.
